# 🍕 Pizza Sales Data Analysis

## 📌 Project Overview
This project analyzes pizza sales data using SQL and Power BI to identify sales trends, revenue performance, customer ordering patterns, and business insights.

## 🛠️ Tools & Technologies
- SQL – Data querying and business analysis
- Power BI – Interactive dashboard and data visualization
- Microsoft Excel – Data handling
- CSV – Dataset

## 📊 Key Performance Indicators (KPIs)
- Total Revenue
- Average Order Value
- Total Pizzas Sold
- Total Orders
- Average Pizzas Per Order

## 🔍 Business Analysis
- Daily and monthly sales trends
- Sales performance by pizza category
- Sales distribution by pizza size
- Best-selling pizzas
- Worst-selling pizzas
- Revenue and order analysis

## 📁 Project Files
| File | Description |
|---|---|
| pizza_project.sql | SQL queries for sales analysis |
| Pizza_Project.pbix | Power BI interactive dashboard |
| pizza_sales.csv | Pizza sales dataset |
| Pizza SQL Queries Report.docx | SQL analysis documentation |

## 🚀 How to Use
1. Download or clone this repository.
2. Import the CSV dataset into your SQL database.
3. Execute the SQL queries.
4. Open the PBIX file using Power BI Desktop.
5. Explore the interactive dashboard.
